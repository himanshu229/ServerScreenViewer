# Changelog

## 1.0.0 - 2026-10-03

- Added Windows Forms host and browser-based view-only screen viewer.
- Added all-monitor or selected-monitor JPEG capture.
- Added generated access key and expiring in-memory browser sessions.
- Added loopback-only default, optional PFX HTTPS, and explicit insecure-remote override.
- Added configurable taskbar visibility, start-minimized behavior, and tray icon.
- Added build, install, uninstall, deployment, and security documentation.
